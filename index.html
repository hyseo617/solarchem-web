이 페이지는 실제 HTTPS로 호스팅된 정적 사이트에서 이 페이지를 보는 사용자 자신의 로컬 Stellarium 26.2 Remote Control API(http://localhost:8090)에 연결할 수 있는지를 실기기로 검증하기 위한 최소 배포 아티팩트입니다. Solarchem 프로덕션 UI, 과학 계산, Electron 어느 것도 포함하지 않습니다.

읽기 전용(read-only): 이 페이지는 checkConnection / getCurrentLocation / getCurrentTime / getSunInfo만 호출합니다 (전부 js/stellarium-api.js의 GET 기반 함수, Solarchem 프로덕션 코드가 실제로 쓰는 것과 동일한 API 경로 — 이 파일은 원본과 byte-for-byte 동일한 사본입니다). setLocation/setDateTime 등 Stellarium의 위치·고도·시간대·날짜/시각을 바꾸는 함수는 이 페이지 어디에서도 호출하지 않습니다.
