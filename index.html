05

Method

Eq.01

σc(λ) = 1000 · ln(10) · ε(λ) / NA

몰 흡광계수로부터 구한 분자 흡수 단면적

Eq.02

rabs(λ, t) = σc(λ) · qdir(λ, t)

파장 λ, 시각 t에서의 스펙트럼별 광자 흡수율

Eq.03

kabs,dir(t) = Σλ=290400 σc(λ) · qdir(λ, t) · Δλ

290–400 nm에 걸쳐 적분한 총 직달 광자 흡수율

Eq.04

Rabs(h) = kabs,dir(h) / kabs,dir(hmax)

해당 날짜의 최대 태양 고도 대비 정규화된 반응

Stellarium connected

Solarchem이 Stellarium에서 현재 위치, 시간, 태양 위치를 실시간으로 받고 있습니다.

How to use Solarchem

  1. Step 1 · Stellarium 실행

    Stellarium 실행

    Remote Control 활성화 (설정 → 플러그인 → Remote Control → 서버 활성화)

    기본 연결: localhost:8090

    macOS: Stellarium을 전체 화면이 아닌 창 모드로, Solarchem과 같은 데스크탑(Space)에 두기 · 나란히 둘 필요는 없고 Solarchem 창에 가려져도 됨 · 최소화하지 않기

    최초 1회만: Remote Control 설정에서 "Enable CORS for the following origin"을 켜고 origin에 — 입력

  2. Step 2 · Solarchem 실행

    Solarchem 앱을 더블클릭해 실행 · 로컬 서버가 자동으로 시작됩니다(Python 설치 불필요)

    Solarchem 프로젝트 폴더 준비 · Python 설치 확인

    Terminal 실행 · Solarchem 폴더로 이동 (경로는 사용자 환경마다 다름)

    로컬 서버 실행: python3 -m http.server 8000

    Windows: Python Launcher가 있으면 py -m http.server 8000, 또는 python -m http.server 8000

    브라우저에서 http://localhost:8000 접속

    이미 이 페이지(—)가 Solarchem입니다 · 별도 설치나 서버 실행이 필요 없습니다

  3. Step 3 · 위치·시간 설정

    Option A — Stellarium에서 직접 위치·시간 설정

    Option B — 코드로 위치·시간 설정: 코드 수정 → 위도·경도·고도·시간대·현지 날짜시간 수정 → 전체 복사 → Stellarium Script Console 열기 → 코드 붙여넣기 → 스크립트 실행 → 위치·시간 변경 확인 → Solarchem으로 복귀

  4. Step 4 · Solarchem 연결

    Connect Stellarium(이미 연결된 경우 Sync Stellarium) 선택

  5. Step 5 · 현재 조건 확인

    Experiment에서 현재 위치·시간·태양의 천문학적 위치 확인

  6. Step 6 · Solar Spectrum 확인

    Solar Spectrum에서 현재 조건의 290–400 nm 직달 UV 광자 스펙트럼 확인

  7. Step 7 · Molecular Response 확인

    Molecular Response에서 Benzophenone, Luteolin, Quercetin의 광자 흡수 반응 비교

    참고 데이터로 돌아가려면 “Use reference data” 선택

코드 수정

5개 값만 수정: 위도·경도·고도·시간대(TIMEZONE, 예: Asia/Seoul, Europe/London, America/New_York)·현지 날짜시간(DATE_TIME, 위 시간대 기준) → 전체 복사 → Stellarium Script Console에 붙여넣고 실행 → Solarchem으로 돌아와 Sync.
